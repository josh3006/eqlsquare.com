# Trick Mind

A tricky-puzzle game: 100 levels in 4 worlds, coins, 3-step hints, a coin shop and rewarded ads.
The same web code runs in a browser and inside the Android app (wrapped with Capacitor).

## Folder layout

| Path | What it is |
|---|---|
| `levels.json` | **Source of truth** for level text: question, hints, solution, explanation, difficulty |
| `LEVELS.md` | Readable list of all 100 puzzles (generated) |
| `app/` | The game itself (plain HTML/CSS/JS, no build step) |
| `app/js/engine.js` | Screens, coins, hints, shop, ads, saving, touch handling |
| `app/js/levels-w1.js` … `levels-w4.js` | How each level plays (objects on screen + what tapping/dragging does) |
| `app/js/levels-data.js` | Level text for the game (generated from `levels.json`) |
| `android/` | Android project generated by Capacitor |
| `mockup.html` | The original clickable mockup |

## Common tasks

```bash
cd puzzle-game
npm run serve        # play in a browser at http://localhost:8080
npm run levels       # after editing levels.json: rebuild LEVELS.md and app/js/levels-data.js
npm install && npm run sync   # copy app/ into the Android project
```

## Android APK

Every push that touches `puzzle-game/` runs **Build Android APK** in GitHub Actions
(`.github/workflows/android-apk.yml`). Download the APK from the run's **Artifacts** section
and install it on an Android phone (allow "Install unknown apps" when asked).

### Signed release builds (for Google Play)

Add these repository secrets (Settings → Secrets and variables → Actions) and the workflow
also produces a signed release APK and an `.aab` bundle for the Play Store:

| Secret | Value |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | Your upload keystore, base64-encoded (`base64 -w0 upload.keystore`) |
| `ANDROID_KEYSTORE_PASSWORD` | Keystore password |
| `ANDROID_KEY_ALIAS` | Key alias |
| `ANDROID_KEY_PASSWORD` | Key password |

Create a keystore once with:

```bash
keytool -genkeypair -v -keystore upload.keystore -alias upload -keyalg RSA -keysize 2048 -validity 10000
```

Keep the keystore and passwords safe and never commit them. Losing them means you can't update the app.
